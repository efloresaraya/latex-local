# Registro de cambios

## 0.1.0 — 2026-10-25

Primera distribución pública preparada: editor local, visor PDF, SyncTeX, guardado protegido, historial con diferencias, respaldos ZIP, referencias por DOI y BibTeX, unión de citas, aviso de etiquetas y conversión de acentos. Incluye CLI, MCP opcional, ejemplo mínimo, pruebas y automatización de verificaciones.

La distribución elimina proyectos y configuraciones privadas, utiliza un entorno Python portable y separa las dependencias opcionales.
