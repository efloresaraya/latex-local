# Revisión de privacidad de la distribución

Se revisaron los archivos públicos, el ZIP, la captura y todos los objetos del repositorio Git local.

- La licencia MIT utiliza la atribución colectiva `LaTeX Local contributors`.
- El commit inicial usa esa misma identidad y una dirección reservada de ejemplo; no contiene una identidad personal. El repositorio fue reconstruido sin conservar commits anteriores ni sus reflogs.
- No se incluyen rutas de usuario, documentos personales, artículos de investigación, experimentos, registro de proyectos, preferencias, respaldos ni cachés de Python o pytest.
- El catálogo distribuido está vacío. Las referencias del ejemplo y de las pruebas son sintéticas.
- La captura muestra únicamente el proyecto de ejemplo, con sus rutas ocultas. El PNG no contiene bloques de texto, EXIF ni otros metadatos opcionales.
- Las licencias y atribuciones de los autores de CodeMirror y PDF.js permanecen intactas.
- El ZIP contiene exclusivamente los archivos del commit publicado en la etiqueta local, sin la carpeta `.git` ni archivos ignorados. Se verificó su integridad y se generó un SHA-256 junto al archivo.

La revisión corresponde a esta distribución. Los documentos que se abran posteriormente en una instalación del editor permanecen en la carpeta elegida por su usuario y no forman parte del paquete original.
